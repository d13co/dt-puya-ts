# Algorand TypeScript

> This is `@d13co/dt-algorand-typescript`, a fork of `@algorandfoundation/algorand-typescript` for [dt-algorand](https://github.com/d13co/dt-algorand/tree/dtalgorand), compiled by [dt-puya-ts](https://github.com/d13co/dt-puya-ts). Install it under the name `@algorandfoundation/algorand-typescript`, as described in [Installing dt-puya-ts](https://github.com/d13co/dt-puya-ts/tree/dtalgorand#installing-dt-puya-ts).

This package contains definitions for the types which comprise Algorand TypeScript which can be compiled to run on the Algorand Virtual Machine using the Puya compiler.
